# nvim-config

My personal Neovim configuration tailored for C, C++, and Rust development.

## Plugins

- **[lazy.nvim](https://github.com/folke/lazy.nvim)** – Package manager
- **[kanagawa.nvim](https://github.com/rebelot/kanagawa.nvim)** – Theme (Dragon variant)
- **[nvim-notify](https://github.com/rcarriga/nvim-notify)** – Floating notification popups
- **[nvim-tree.lua](https://github.com/nvim-tree/nvim-tree.lua)** – File explorer sidebar
- **[nvim-web-devicons](https://github.com/nvim-tree/nvim-web-devicons)** – File icons
- **[bufferline.nvim](https://github.com/akinsho/bufferline.nvim)** – Top tabline/buffers
- **[lualine.nvim](https://github.com/nvim-lualine/lualine.nvim)** – Statusline
- **[neoscroll.nvim](https://github.com/karb94/neoscroll.nvim)** – Smooth scrolling
- **[nvim-treesitter](https://github.com/nvim-treesitter/nvim-treesitter)** – Advanced syntax highlighting
- **[nvim-autopairs](https://github.com/windwp/nvim-autopairs)** – Auto-close pairs (), {}, []
- **[indent-blankline.nvim](https://github.com/lukas-reineke/indent-blankline.nvim)** – Indentation guides
- **[telescope.nvim](https://github.com/nvim-telescope/telescope.nvim)** – Fuzzy finder
- **[plenary.nvim](https://github.com/nvim-lua/plenary.nvim)** – Utility functions required by Telescope
- **[gitsigns.nvim](https://github.com/lewis6991/gitsigns.nvim)** – Git status in the gutter
- **[toggleterm.nvim](https://github.com/akinsho/toggleterm.nvim)** – Floating/integrated terminal
- **[cord.nvim](https://github.com/vyfor/cord.nvim)** – Discord RPC
- **[nvim-lspconfig](https://github.com/neovim/nvim-lspconfig)** – Language Server Protocol configs (clangd, 
ust-analyzer, lua_ls)
- **[nvim-cmp](https://github.com/hrsh7th/nvim-cmp)** – Completion engine (with cmp-nvim-lsp, cmp-buffer, cmp-path)
- **[LuaSnip](https://github.com/L3MON4D3/LuaSnip)** + **[friendly-snippets](https://github.com/rafamadriz/friendly-snippets)** – Snippet engine and collection
